# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v26.1.2-mc26.1.x] - 2026-06-27

### Changed

- Text formatting configs now support defining custom colors in hexadecimal format

### Fixed

- Fix missing options in the tooltip lines settings

## [v26.1.1-mc26.1.x] - 2026-06-26

### Added

- Add a config option for controlling the maximum description width
- Add a config option controlling the tooltip hint for revealing descriptions

### Changed

- Refactor text style options, so they no longer rely on defining legacy chat formatting codes
- Activation keys for showing additional tooltip information are now represented by sprites instead of text
- Rename some other config options

## [v26.1.0-mc26.1.x] - 2026-04-30

### Changed

- Update to Minecraft 26.1.x
